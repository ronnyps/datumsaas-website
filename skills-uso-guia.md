# Guia de uso de skills de marketing

## Resumen rapido
Estos 6 skills cubren un flujo completo de marketing:
investigar cliente -> disenar estrategia psicologica/SEO -> escribir copy -> editar/pulir copy -> escalar SEO.

## 1) customer-research
- Para que sirve: descubrir pains, triggers, objeciones, JTBD y lenguaje real del cliente (VOC).
- Como se usa:
1. Elegir modo: analizar assets existentes (entrevistas, tickets, encuestas) o investigar fuentes externas (Reddit, G2, foros).
2. Extraer temas + citas textuales + nivel de confianza.
3. Entregar sintesis, quote bank, personas o JTBD map.

## 2) marketing-psychology
- Para que sirve: aplicar sesgos/cognitive models a mensajes, pricing y UX de conversion.
- Como se usa:
1. Definir que comportamiento quieres cambiar (clic, registro, compra, upgrade).
2. Elegir modelos adecuados (ej. social proof, loss aversion, anchoring, Hick's law).
3. Implementar tacticas concretas de forma etica y medir impacto.

## 3) seo-audit
- Para que sirve: diagnosticar por que no rankea un sitio/pagina.
- Como se usa:
1. Auditar por prioridad: indexacion/crawl -> tecnico -> on-page -> contenido.
2. Reportar hallazgos con: issue, impacto, evidencia, fix y prioridad.
3. Entregar plan priorizado (quick wins + fixes criticos).
- Nota clave: no concluir "sin schema" solo con HTML estatico/curl; validar con renderizado (Rich Results Test, etc.).

## 4) programmatic-seo
- Para que sirve: crear muchas paginas SEO con plantillas + datos, evitando thin content.
- Como se usa:
1. Validar patron de keywords y demanda.
2. Definir data source y plantilla con valor unico real por pagina.
3. Disenar URLs en subfolders, linking interno hub-spoke, sitemap/indexacion y monitoreo post-lanzamiento.
4. Priorizar calidad sobre volumen.

## 5) copywriting
- Para que sirve: escribir copy nuevo o reescribir copy para convertir.
- Como se usa:
1. Recoger contexto: objetivo de pagina, audiencia, oferta, objeciones, fuente de trafico.
2. Redactar por secciones (hero, beneficios, prueba, objeciones, CTA final).
3. Entregar variantes de headline/CTA + racional.
4. Regla central: claridad, especificidad, beneficios y lenguaje del cliente.

## 6) copy-editing
- Para que sirve: mejorar copy ya existente sin cambiar el mensaje base.
- Como se usa:
1. Aplicar las 7 sweeps en orden: Clarity -> Voice/Tone -> So What -> Prove It -> Specificity -> Emotion -> Zero Risk.
2. Iterar corrigiendo y revalidando sweeps previos.
3. Opcional: panel de expertos con scoring para paginas criticas.

## Orden recomendado de uso conjunto
1. customer-research
2. marketing-psychology
3. seo-audit (si ya hay sitio) o programmatic-seo (si vas a escalar paginas)
4. copywriting
5. copy-editing

## Regla practica para elegir rapido
- "No se que decir" -> customer-research
- "Quiero persuadir mejor" -> marketing-psychology
- "No rankeo" -> seo-audit
- "Quiero 100+ paginas SEO" -> programmatic-seo
- "Necesito copy nuevo" -> copywriting
- "Tengo copy, pero esta flojo" -> copy-editing
